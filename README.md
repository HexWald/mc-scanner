# MC Scanner

Небольшой GUI-сканер Minecraft-серверов на Java Swing. Проверяет адреса и порты, получает статус сервера, пробует аккуратно определить причину отказа во входе и сохраняет результат в TXT, CSV и JSON.

**Текущая версия: 2.1.0**. Java 8 или новее. Windows, Linux, macOS.

## Что умеет

- принимать IP, домены, список адресов и простые диапазоны;
- проверять несколько портов подряд;
- показывать версию Minecraft, протокол, онлайн, лимит игроков, ping и MOTD;
- определять Paper, Purpur, Spigot, Bukkit, Forge, NeoForge, Fabric, Quilt, гибридные ядра и прокси, если сервер раскрывает эту информацию;
- отличать открытую регистрацию от online mode, whitelist, бана, переполненного сервера, несовместимой версии и обязательных клиентских модов;
- сохранять список модов: коротко в TXT и полностью в CSV/JSON;
- повторять проверку через заданный интервал и показывать изменения;
- работать в тёмной, светлой или системной теме.

Если сервер скрывает своё ядро, в отчёте будет `Vanilla / hidden`. Это честнее, чем угадывать по одной строке версии. Если сервер прислал неполные данные о модах, результат помечается как `UNKNOWN` или `+`.

## Быстрый запуск

Готовый JAR уже лежит в репозитории:

```powershell
java -jar MCScanner.jar
```

На Windows можно использовать `run-with-console.bat`, чтобы видеть сообщения сканера и возможные ошибки.

Нужна Java 8 или новее. Проверить установленную версию:

```powershell
java -version
```

## Основные поля

- `Server IPs`: IP, домены или диапазоны;
- `Start Port`: первый порт;
- `Scan Amount`: сколько портов проверить;
- `Check Nickname`: ник для пробного входа;
- `Speed`: скорость и число потоков;
- `Monitoring`: повторять сканирование через N минут;
- `Theme`: тема интерфейса.

Примеры адресов:

```text
127.0.0.1
play.example.org
192.168.1.10 192.168.1.11
192.168.1.10-192.168.1.20
```

## Результаты

Файлы появляются в `results/`:

```text
MCScanner_Results_yyyy-MM-dd_HHmmss.txt
MCScanner_Results_yyyy-MM-dd_HHmmss.csv
MCScanner_Results_yyyy-MM-dd_HHmmss.json
```

В отчёт попадают адрес и порт, версия, протокол, ядро, игроки, ping, MOTD, статус доступа и текст отказа.

Список модов устроен по-разному для каждого формата:

- **TXT**: количество и первые восемь ID, чтобы файл оставался читаемым;
- **CSV**: полный список в одной ячейке, вместе с версиями;
- **JSON**: массив объектов с `id` и `version`.

`UNKNOWN` означает, что сервер не сообщил достаточно данных. `null` в JSON имеет тот же смысл.

## Сборка

Windows:

```powershell
build.bat
```

Linux/macOS:

```bash
chmod +x build.sh
./build.sh
```

После сборки рядом с исходниками появится обновлённый `MCScanner.jar`. Для JSON используется библиотека из `lib/json-20231013.jar`.

## Скорости сканирования

| Режим | Потоки | Задержка |
| --- | ---: | ---: |
| `MEDIUM` | 20 | 500 ms |
| `FAST` | 50 | 125 ms |
| `VERY_FAST` | 100 | 50 ms |
| `DANGEROUS` | 200 | 10 ms |

Для обычной проверки лучше использовать `MEDIUM` или `FAST`. Режим `DANGEROUS` может упереться в ограничения сети, firewall или ресурсы компьютера.

## Ограничения

Детекция зависит от того, что сервер отдаёт в status ping и во время пробного подключения. Скрытое ядро, урезанный список модов или собственное сообщение сервера могут оставить часть полей неопределённой.

Сканируй свои серверы или инфраструктуру, на которую у тебя есть разрешение. Подробные рекомендации по безопасной проверке лежат в [docs/responsible-scanning.md](docs/responsible-scanning.md).
