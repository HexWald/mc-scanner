# MC Scanner

Небольшой GUI-сканер Minecraft-серверов на Java Swing.

Он проверяет IP и порты, находит доступные серверы, собирает основную информацию и сохраняет результаты в TXT, CSV и JSON.

## Последнее обновление

MC Scanner теперь отдельно определяет ядро сервера и необходимость клиентских модов. Он узнает Paper, Purpur, Spigot, Forge, NeoForge, Fabric, Quilt, популярные гибридные ядра и прокси. Для Forge читаются как старые `modinfo`, так и новые `forgeData`, включая упакованный формат современных версий.

В результатах появились компактные поля `Core` и `Mods`. Значение `UNKNOWN` означает, что сервер не сообщил достаточно данных. Обычная строка версии помечается как `Vanilla / hidden`: по ней нельзя надежно отличить чистую Vanilla от ядра, которое скрывает своё название.

## Предыдущее обновление

Сканер научился нормально читать причину отказа во входе. Раньше почти любой ответ сервера сводился к `whitelist: да или нет`, поэтому обязательная авторизация, несовместимая версия или Forge-сервер могли выглядеть одинаково.

Теперь для каждого найденного сервера сохраняется отдельный статус доступа:

- вход открыт;
- включен online mode и нужен авторизованный Minecraft-аккаунт;
- nickname отсутствует в whitelist;
- на клиенте нужны Forge, NeoForge, Fabric или другие моды;
- игрок или IP заблокирован;
- сервер заполнен;
- не подходит версия Minecraft;
- сработало ограничение частоты подключений;
- сервер отклонил вход по собственной причине.

Сам текст кика тоже сохраняется в TXT, CSV и JSON. Если сервер использует своё сообщение, оно не теряется и остается рядом с общей категорией. Заодно исправлен формат Login Start для Minecraft 1.19–1.20.1: раньше лишние байты могли скрывать настоящую причину отказа.

### Удаление скриншотов

Из MC Scanner полностью убраны скриншоты серверов. Для каждого снимка приходилось отдельно запускать Minecraft-бота, локальный viewer и headless-браузер. При массовом сканировании это съедало слишком много памяти и процессорного времени, занимало место на диске и заметно задерживало завершение проверки. Для вспомогательной функции такие расходы себя не оправдывали.

Вместе со скриншотами удалены настройки из интерфейса, отдельный Node.js helper и лишние зависимости. Теперь для запуска снова нужна только Java, а сканирование заканчивается сразу после проверки портов и сохранения результатов.

## Что умеет

- сканировать один IP, список IP или простой диапазон;
- проверять много портов подряд, начиная с выбранного порта;
- показывать версию, ядро сервера, протокол, онлайн, максимум игроков, ping и MOTD;
- проверять возможность входа и объяснять причину отказа;
- экспортировать результаты в `TXT`, `CSV` и `JSON`;
- запускать повторный мониторинг каждые N минут и показывать изменения;
- открывать папку с результатами и чистить старые файлы прямо из окна;
- переключать тему: dark, light или system.

## Как запустить

Нужна Java 8 или новее. Если уже есть `MCScanner.jar`:

```powershell
java -jar MCScanner.jar
```

На Windows можно запустить через `run-with-console.bat`, чтобы окно консоли оставалось открытым и показывало возможные ошибки.

## Сборка

Windows:

```powershell
build.bat
```

Linux или macOS:

```bash
chmod +x build.sh
./build.sh
```

После сборки рядом появится `MCScanner.jar`.

## Использование

Поле `Server IPs` принимает отдельные адреса, домены и простые диапазоны:

```text
127.0.0.1
play.example.org
192.168.1.10 192.168.1.11 192.168.1.12
192.168.1.10-192.168.1.20
```

Основные поля:

- `Start Port` — первый порт для проверки;
- `Scan Amount` — сколько портов проверить подряд;
- `Check Nickname` — ник для пробного входа;
- `Speed` — число потоков и задержка между задачами;
- `Monitoring` — повторять скан каждые N минут;
- `Theme` — dark, light или system.

После скана кнопка `Open Results` открывает папку с файлами, а `Clean Output` удаляет старые результаты.

## Результаты

Файлы сохраняются в папку `results/`. На каждый запуск создаются:

```text
MCScanner_Results_yyyy-MM-dd_HHmmss.txt
MCScanner_Results_yyyy-MM-dd_HHmmss.csv
MCScanner_Results_yyyy-MM-dd_HHmmss.json
```

Экспорт содержит адрес и порт сервера, версию и номер протокола, определенное ядро, необходимость клиентских модов, количество игроков, ping, MOTD, статус доступа и читаемую причину кика. Поля с неопределенным результатом сохраняются как `UNKNOWN` в TXT/CSV и `null` в JSON.

## Скорости скана

| Режим | Потоки | Задержка |
| --- | ---: | ---: |
| `MEDIUM` | 20 | 500 ms |
| `FAST` | 50 | 125 ms |
| `VERY_FAST` | 100 | 50 ms |
| `DANGEROUS` | 200 | 10 ms |

Для обычного использования лучше начинать с `FAST` или `MEDIUM`. Режим `DANGEROUS` может упереться в ограничения сети, firewall или ресурсы слабого компьютера.

## Репозиторий

`MCScanner.jar` оставлен в репозитории специально, чтобы программу можно было скачать и запустить без самостоятельной сборки. Результаты сканирования и временные build-файлы в git не добавляются.

## Важно

Сканируй свои серверы или те, где у тебя есть разрешение. Большие диапазоны и агрессивные режимы могут выглядеть для чужой инфраструктуры как атака.
